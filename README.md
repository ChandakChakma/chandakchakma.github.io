# chandakchakma.github.io

Personal academic website of Chandak Chakma. Served by GitHub Pages at https://chandakchakma.github.io.

Plain HTML, no build step. Based on [Jon Barron's website](https://github.com/jonbarron/jonbarron.github.io).

## Files

- `index.html` – the main page (bio and papers). Edit the text here.
- `notes.html` – the Notes page, linked from the box under the papers.
- `stylesheet.css` – fonts and colours.
- `images/` – profile photo and one thumbnail per paper.
- `data/` – CV and paper PDFs.

## To update

1. Edit `index.html`.
2. `git add -A && git commit -m "update" && git push`.
3. GitHub Pages rebuilds in about a minute.
