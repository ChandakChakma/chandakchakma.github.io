9 Learnability

Key result | the \(p(1-p)\) law

For a binary reward with success probability \(p\), \(\operatorname{Var}[R]=p(1-p)\), largest (\(1/4\)) at \(p=1/2\). A GRPO group of size \(G\) carries a signal only if its rewards are not all equal: \[\Pr[\text{informative group}]=1-p^G-(1-p)^G .\]

Worked example | \(G=8\)
\(p\) (or \(1-p\)) \(0.5\) \(0.9\) \(0.99\)
informative groups \(0.992\) \(0.570\) \(0.077\)

A problem solved \(99\%\) of the time gives a signal in only \(1\) group out of \(13\). This is the arithmetic behind “make problems at the edge of the Solver’s ability”. R-Zero motivates the same target with a lower bound on the Solver’s remaining learning potential that grows with \(\hat p(1-\hat p)\).

Pitfall

The law needs the true success rate. In label-free self-play we only measure agreement \(\hat p\) with a pseudo-label, which equals \(p\) only when the label is right.

10 Proposer rewards: a comparison

Method Challenger (proposer) reward Truth from Main limit
Asymmetric self-play (2017) \(r_A=\gamma\max(0,\,t_B-t_A)\), \(r_B=-\gamma t_B\) (times to finish) environment needs a reversible world
PAIRED (2020) regret \(=U(\pi_{\mathrm{antagonist}})-U(\pi_{\mathrm{protagonist}})\) environment reward antagonist must be strong
Absolute Zero (2025) \(1-\bar r\) if \(0<\bar r<1\), else \(0\) (\(\bar r\) = solve rate) Python executor code only
R-Zero (2025) \(\max\!\big(0,\ 1-2|\hat p-\tfrac12|-\lambda|C_k|/B\big)\) none (majority vote) labels decay
SOAR (2026) \(\mathrm{Perf}_H(\mathrm{Train}(\theta,D_\phi))-\mathrm{Perf}_H(\theta)\) labeled hard set \(H\) needs labels on \(H\)
Learning progress (2007) decrease of the learner’s error over time environment needs a measurable error

SOAR (Sundaram, Kempe and Ollivier, ICML 2026) is the current accepted frontier. It is bilevel: the teacher writes a problem set \(D_\phi\), the student trains on it briefly, and the teacher is paid by the student’s real gain on hard problems it could not solve (\(0\) of \(128\) samples). Grounded rewards beat learnability rewards, and well-posed questions matter more than correct answers. Its gap is the labeled hard set \(H\). PowerPlay (Schmidhuber, 2011) is the conceptual root: keep searching for the simplest problem the current solver cannot yet solve.

Worked example | what R-Zero’s reward cannot see

Ten Solver answers: four say \(20\), four say \(22\), two have no boxed answer. Then \(\hat p=4/10\) and \(r_{\mathrm{unc}}=1-2|0.4-0.5|=0.8\), a high reward, and the question passes the \(3\)–\(7\) filter. In the released code the label is whichever of \(20\) and \(22\) appeared first (Python’s max returns the first maximal key), and each unboxed answer counts as a vote for the string "None" (the question is dropped later only if "None" wins the vote). The reward cannot tell a two-way split from scattered guessing, and the label is a coin flip. Always read the code.

Why it matters for self-play

Rewards built only from the Solver’s agreement measure difficulty, not truth. Rewards grounded in real progress (SOAR, PAIRED) need a source of truth. A grounded signal without labels is the open problem.

11 Learning from noisy labels

Key result | random noise only shrinks the signal

Suppose the observed reward \(\tilde R\) flips the true reward with probability \(\eta\), independently of which response was sampled. Then \(\mathbb{E}[\tilde R\mid y]=\eta+(1-2\eta)R(y)\) and, because \(\mathbb{E}[\nabla_\theta\log\pi_\theta]=0\), \[\mathbb{E}\big[\tilde R\,\nabla_\theta\log\pi_\theta\big]=(1-2\eta)\,\nabla_\theta J .\] The gradient keeps its direction whenever \(\eta<1/2\); only its size shrinks.

Key result | correlated noise biases the signal

If the label error depends on the response, write \(\tilde R=R+\delta(x,y)\). Then \(\mathbb{E}[\tilde R\,\nabla_\theta\log\pi_\theta]=\nabla_\theta J+\mathbb{E}\big[\delta\,\nabla_\theta\log\pi_\theta\big]\): an extra push toward whatever responses \(\delta\) favors.

Worked example | the majority-vote reward

The pseudo-label is the mode \(m(x)\) of the Solver’s own samples, and the reward is \(\mathbf{1}[\text{answer}(y)=m(x)]\). Its expected value is \(\pi_\theta(m\mid x)\), which is maximized by putting all mass on \(m\), whether or not \(m\) is correct. Example: \(\pi(20)=0.40\), \(\pi(22)=0.35\), other answers \(0.25\), and the truth is \(22\). The vote makes \(20\) the label and training pushes \(\pi(20)\) toward \(1\): the model becomes confidently wrong.

Why it matters for self-play

This is the mechanism behind “rise, then fall”. Early on the mode is usually right (R-Zero’s labels are \(79\%\) correct in round 1), so sharpening helps. As the Challenger writes harder questions, the mode is wrong more often (\(63\%\) correct by round 3), and the same sharpening now teaches errors.

Exercises

Exercise 5. For \(G=4\) and \(p=0.75\), what fraction of groups is informative?

Show answer

\(1-0.75^4-0.25^4=1-0.316-0.004=0.680\).

Exercise 6. With symmetric label noise \(\eta=0.3\), by what factor is the expected gradient scaled? What happens at \(\eta=0.5\)?

Show answer

\(1-2\eta=0.4\). At \(\eta=0.5\) the factor is \(0\): the labels carry no signal.
